### Die Vielfalt der Wohnsituationen sichtbar machen

Alle statistischen Grafiken des o.g. Vortrags lassen sich mit dem hier abgelegten R-Code reproduzieren. Dabei zeigt die erste Datei, wie die Daten im Unterordner `daten` aus der Zensusdatenbank abgerufen wurden, sowohl per API mit dem {restatis} Paket als auch durch Einlesen von flatfile-csv-Dateien, die über die Weboberfläche heruntergeladen wurden.

Die Grafiken können vollständig mit den hier abgelegten Datensätzen erzeugt werden. Ebenfalls sind alle mit dem R-Code erstellten Diagramme im `img` Ordner abgelegt.
